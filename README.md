# Hermes Skill: Codebase Inspection

A small, shareable skill package extracted from the Hermes catalog.

## What it does

Measure a codebase’s size, languages, and composition without changing it.

## Example

> Give me a read-only codebase report with language ratios, LOC, test locations, and likely entry points.
